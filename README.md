# MoneySaver

MoneySaver - веб-приложение для учета доходов и расходов пользователей, которое поможет вам стать более финансово грамотным.

## Используемый стек
- Язык: Python 3
- База данных: SQLite
- Backend: FastAPI
- Шаблоны (frontend): Jinja2 
- HTTP-тестирование: Swagger / Postman
- Контроль версий: Git

## Доступный функционал:
- Изменить/просмотреть свой баланс (начало с 0)
- Добавить/просмотреть/изменить/удалить доход
- Добавить/просмотреть/изменить/удалить расход
- Для каждого дохода и расхода можно также добавить/просмотреть/изменить/удалить комментарий
- Просмотреть/изменить цель


## Описание базы данных

Таблица пользователей:

| имя        | тип данных | ограничения      | описание  атрибута                                                                         |
| ---------- | ---------- | ---------------- |--------------------------------------------------------------------------------------------|
| id         | integer    | primary key      | первичный ключ пользователя                                                                |
| balance    | integer    | not null         | Баланс пользователя основанный на введённом значении пользователя и его доходах и расходах |
| username   | text       | not null         | имя пользователя                                                                           |
| email      | text       | not null, unique | email пользователя, по которому его можно отличить от других пользователей                 |
| password   | text       | not null         | зашифрованный пароль пользователя                                                          |
| goal       | text       | -                | цель пользователя, заполняется в формате: "название цели#сумма цели"                       |
| created_at | text       | -                | время регистрации пользователя                                                             |


Таблица доходов и расходов:

| имя            | тип данных | ограничения            | описание атрибута                                 |
| -------------- | ---------- | ---------------------- | ------------------------------------------------- |
| id             | integer    | primary key            | первичный ключ записи                             |
| user_id        | integer    | foreign key users (id) | внешний ключ, связь с таблицей пользователей      |
| operation_type | integer    | not null               | тип операции, 1 означает расход, 2 означает доход |
| value          | integer    | not null               | значение дохода или расхода                       |
| comment        | text       | -                      | комментарий к записи                              |
| created_at     | text       | -                      | время регистрации записи                          |
